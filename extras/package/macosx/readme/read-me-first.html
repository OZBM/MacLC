MacLC — Read Me First

Installation: Drag MacLC into your Applications folder. Do not run it from the disk image.

First launch: "Open Anyway"

  1. Open MacLC once from Applications. macOS will report that it cannot verify MacLC is free of malware. Click Done.
  2. Open System Settings > Privacy & Security, scroll down to the Security section.
  3. Next to "MacLC was blocked to protect your Mac", click Open Anyway.
  4. Confirm Open Anyway and authenticate with Touch ID or your password.

The "Open Anyway" button remains available for about an hour after the blocked attempt. This step is needed only once; after that, MacLC opens normally. A newly downloaded version asks once again.

Alternative for Terminal users:

xattr -dr com.apple.quarantine /Applications/MacLC.app

This removes the "downloaded from the internet" flag and produces the exact same effect as clicking Open Anyway.

Why does macOS ask for this?

macOS opens downloaded apps without asking only if they are signed with an Apple Developer ID certificate and notarized by Apple. That requires a paid Apple Developer Program membership (99 USD per year) and sending every build to Apple.

MacLC is a free, open-source, non-commercial project: it is signed "ad hoc" (a signature that proves the files were not altered since they were built, but does not identify the author to Apple). macOS therefore cannot check who made it and asks you to confirm once. This is not a sign that the app is damaged or dangerous; the source code is public (https://github.com/OZBM/MacLC) and the release page lists the SHA-256 of the disk image to compare:

shasum -a 256 maclc-1.1.1.dmg

Damaged alert: If macOS says MacLC "is damaged and can't be opened", the download is incomplete or altered. Download it again and check the SHA-256. Do not bypass that one.

Requirements & Optional Extras

Requirements: macOS 26 or later, Apple Silicon. Everything needed is inside the app; nothing else to install.

Optional extras:

  • yt-dlp: Optional, needed only for File > Open Web Video (brew install yt-dlp).
  • SVP 4 Mac: Optional, needed only if using the SVP motion interpolation engine.

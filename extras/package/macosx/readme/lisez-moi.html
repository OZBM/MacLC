MacLC — Lisez-moi en premier

Installation : Glissez MacLC dans votre dossier Applications. Ne lancez pas l'application depuis l'image disque.

Premier lancement : « Ouvrir quand même »

  1. Lancez MacLC une première fois depuis vos Applications. macOS indique qu'Apple n'a pas pu vérifier que MacLC ne contient pas de logiciel malveillant. Cliquez sur Terminé.
  2. Ouvrez Réglages Système > Confidentialité et sécurité, puis faites défiler jusqu'à la section Sécurité.
  3. À côté de la mention « L'ouverture de MacLC a été bloquée pour protéger votre Mac », cliquez sur Ouvrir quand même.
  4. Confirmez en cliquant sur Ouvrir quand même et authentifiez-vous avec Touch ID ou votre mot de passe.

Le bouton « Ouvrir quand même » reste accessible pendant environ une heure après la tentative bloquée. Cette manipulation n'est nécessaire qu'une seule fois : MacLC s'ouvrira ensuite normalement, Une nouvelle version téléchargée vous le redemandera une fois.

Alternative dans le Terminal :

xattr -dr com.apple.quarantine /Applications/MacLC.app

Cette commande retire l'attribut « téléchargé depuis Internet » et produit le même effet que le bouton Ouvrir quand même.

Pourquoi macOS demande-t-il cela ?

macOS ouvre les applications téléchargées sans demander confirmation uniquement si elles sont signées avec un certificat Developer ID d'Apple et notarisées par Apple. Cela nécessite une adhésion payante à l'Apple Developer Program (99 USD par an) et l'envoi de chaque binaire à Apple.

MacLC est un projet libre, gratuit et non commercial : il est signé « ad hoc » (une signature qui garantit que les fichiers n'ont pas été modifiés depuis leur compilation, mais qui n'identifie pas l'auteur auprès d'Apple). macOS ne peut donc pas vérifier qui a conçu l'application et vous demande confirmation une fois. Ce n'est pas le signe que l'application est endommagée ou dangereuse ; le code source est public (https://github.com/OZBM/MacLC) et la page de version fournit le SHA-256 de l'image disque pour comparaison dans le Terminal :

shasum -a 256 maclc-1.1.1.dmg

Alerte d'application endommagée : Si macOS indique que MacLC « est endommagé et ne peut pas être ouvert », le téléchargement est incomplet ou a été altéré. Téléchargez-le à nouveau et vérifiez son empreinte SHA-256. Ne contournez pas cette alerte.

Configuration requise et compléments optionnels

Configuration requise : macOS 26 ou ultérieur, Apple Silicon. Tout le nécessaire est intégré dans l'application ; rien d'autre n'est à installer.

Compléments optionnels :

  • yt-dlp : Optionnel, utile uniquement pour la commande « Open Web Video » du menu Fichier (brew install yt-dlp).
  • SVP 4 Mac : Optionnel, utile uniquement si vous utilisez le moteur d'interpolation de mouvement SVP.
